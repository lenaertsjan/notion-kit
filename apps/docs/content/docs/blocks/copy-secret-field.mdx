Import `CopySecretField` from `@notion-kit/ui/copy-secret-field`.

## Anatomy

```tsx
import { CopySecretField } from "@notion-kit/ui/copy-secret-field";

<CopySecretField
  label="New API key"
  value={apiKey}
  description="Store this key somewhere safe."
  warning="This key is shown only once and cannot be retrieved again."
/>;
```

The component only ever holds the `value` prop you pass it; it never persists
the secret anywhere, so keep it out of application state you don't control.

## API Reference

### CopySecretField

| Prop          | Type               | Default | Description                                                     |
| ------------- | ------------------ | ------- | ----------------------------------------------------------------- |
| `label`       | `string`           | -       | Label describing the secret, e.g. `"API key"`.                   |
| `value`       | `string`           | -       | The secret value. Shown by default; toggle to hide it.           |
| `description` | `React.ReactNode`  | -       | Helper text rendered under the label.                            |
| `warning`     | `React.ReactNode`  | -       | Rendered as a soft callout with `role="note"`.                   |
| `onCopied`    | `() => void`       | -       | Called after the value is written to the clipboard.              |
| `className`   | `string`           | -       | Applied to the root `Field`.                                     |
